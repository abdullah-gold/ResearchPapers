VExecution Roadmap

Sixty-four working days, three students, one supervisor. The schedule below is anchored to the Spring 2026 term and is expressed in relative day numbers (D1–D64) so it can be mapped onto actual calendar dates once the term start is confirmed. Each phase has an exit criterion — a demonstrable artefact, not an activity — because a phase without a gate is a phase that slips.

Standing rules

  • No single person owns a module alone. Every module has a primary and a reviewer. The reviewer must be able to run it.
  • Interface-first. Agree the data contracts (§3.6) in week 1 and do not change them without a version bump and a note in the ADR log.
  • Merge train. No branch lives more than three days. Every merge triggers CI: lint, unit tests, the causality test and the integration test.
  • Friday demo. Thirty minutes, all three present, run the pipeline live. If it does not run, that is the work for the weekend.

The critical path, and the three places it can break

Critical path: P1 (data) → P3/P4 (features + sentiment) → P5 (splits) → P6 (models) → P8 (evaluation) → P9 (backtest) → P11 (thesis).

Break #1 — P4 slips. The sentiment engine is the longest-lead item and the only module with a genuine external dependency (the lexicon quality). If the lexicon is not ready by D22, everything downstream compresses. Mitigation: build the Loughran–McDonald baseline arm and the CDW pipeline first, with a placeholder lexicon, so the machinery is complete and tested; refine the crypto lexicon in parallel with the model work.

Break #2 — the data volume is smaller than expected. If RSS feeds only retain 90 days of history, the sentiment panel is 90 days and the entire sentiment analysis is underpowered. Mitigation: verify feed history depth in P1 (D4–D6), before committing to the design. If history is shallow, pivot the sentiment panel to a rolling-window, cross-sectional design — more assets over fewer days rather than fewer assets over many days — and restate the power analysis in the thesis. This check must happen in the first week.

Break #3 — P6 overruns. Nine models × 5 seeds × hyperparameter search on CPU is genuinely expensive. Mitigation: run the search on a reduced feature set first, fix the search budget, and use a single GPU instance for the deep models. If GPU access is unavailable, drop GRU and M6 to a single seed and say so explicitly in the results section rather than reporting a weaker comparison silently.

5.5 Common failure modes

Failure modeLikelihoodImpactPrevention
Leakage inflates results — centred windows, full-sample scalers, lead–lag estimated on the full datasetHighFatalThe causality test, written before the first model. Never fit a transform outside the training fold. Review the feature code specifically for shift(− and centred windows.
RSS history too shallowMediumFatalVerify in D4–D6. Keep a cross-sectional design ready as the fallback.
Sentiment lexicon is poor — κ below 0.4, or the benchmark shows crypto-specific terms degrading general financial sentimentMediumHighBuild the Loughran–McDonald arm first so there is always a working sentiment measure. Iterate the crypto lexicon with double-labelled samples.
Class imbalance inflates accuracy — headline accuracy near 55% presented as strongHighHighAlways report balanced accuracy and MCC alongside accuracy. Set a threshold on validation by F1 maximisation.
T3 assets contribute nothing — insufficient history, so the high-risk tier is emptyHighHighEnforce min_history_days; use variable-length sequences or per-tier lookbacks; monitor per-asset sample counts in the coverage report.
API rate limits / outagesHighMediumRate limiter, circuit breaker, retries with backoff, cached raw responses, graceful degradation, a freshness panel.
Scope creep into a new architectureMediumFatalThe contribution list in §2.4 is the scope. New ideas go in a "Future Work" section, not into the implementation.
Writing starts too lateHighHighWrite the methodology chapter as the work happens (Thursday slot). Draft the results chapter from the registry, not from memory.
